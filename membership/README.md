# Membership Module Folder

Public membership pages are organized here:

- `membership/member-register.php`
- `membership/member-dashboard.php`
- `membership/member-verify.php`
- `membership/download-member-receipt.php`

Root files (`member-register.php`, `member-dashboard.php`, `member-verify.php`, `download-member-receipt.php`) are compatibility wrappers that load these files.

Admin membership files remain under:

- `admin/`
- `admin/actions/`
